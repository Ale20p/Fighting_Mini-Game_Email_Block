# Fighting_Mini-Game_Email_Block
This project will be to develop a code block that can be placed into an email template on Salesforce. This code block will be a mini 2D Mortal Kombat style fighting game that can work on all email or most email clients and on mobile and desktop.

The background will be imported as a .png or a .gif and the characters themselves will be imported, but there will have to be .png of each animation I think. 

There needs to be healthbars and the attacks will be very backsick. There will be probably only 2 attacks and they will be determind at the time of creating the email itself.

The block itself has to be the same size as a TITTC block.
